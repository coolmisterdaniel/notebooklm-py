# Проверка установки NotebookLM на VPS

Дата: 16 ноября 2026 года. База: v0.8.6, 956400aa7af6b61b4cb988a24c9a081a3abc4ee8.
Проверка — целевой обзор, а не полный независимый аудит всех строк и всех зависимостей.

Проверены документация installation.md, mcp-guide.md, SECURITY.md, SKILL.md,
сборочный hatch_build.py, pyproject.toml и uv.lock; ключевые пути авторизации,
MintService, сохранения учётных данных, обновления сессии, журналирования,
ограничений URL, скачивания, загрузки файлов и запуска MCP.

## Результаты

- Master Token обменивается через gpsoauth на android.clients.google.com;
  OAuthLogin, MergeSession и RotateCookies используют accounts.google.com.
  gpsoauth включает проверку TLS. Долговременный токен предоставляет доступ
  шире NotebookLM. Рекомендуется отдельный Google-аккаунт.
- Токены и cookies сохраняются открытым текстом, с правами 0600 внутри 0700.
  Атомарная запись и блокировки снижают риск повреждения файлов, но не защищают
  от root, вредоносного кода под тем же пользователем или утечки резервной копии.
- Поля секретов скрыты из repr; присутствуют очистка ошибок и редактирование логов.
  Подробные отладочные логи и внешние обработчики исключений всё равно требуют
  осторожности. В запуске отключены подробные трассировки и core dump.
- gpsoauth 2.0.0 вызывает requests.post без явного тайм-аута: сетевой сбой
  способен задержать обмен. Автоматический повтор ошибок токена не настраивался.
- NOTEBOOKLM_REFRESH_CMD умеет запускать внешнюю команду, включая opt-in shell.
  Через штатный запуск переменные окружения не наследуются, этот механизм выключен.
- В проекте нет фонового обновления пакета; uv/pip отсутствуют в командах запуска.
  Playwright может скачать Chromium при браузерном входе. Дополнение browser
  на VPS не устанавливается: для восстановления через Master Token достаточно headless.
- MCP stdio не слушает сетевой порт; REST и HTTP MCP не запускаются.
  MCP-загрузка локальных файлов ограничена /var/lib/notebooklm/uploads;
  код запрещает ссылки, пути за пределами разрешённых корней и известные файлы
  авторизации. Скачивания проверяют доверенные домены при перенаправлениях.
- Необязательный fallback загрузки URL использует отдельный запрос без cookies,
  проверяет публичные DNS-адреса и ограничивает перенаправления и размер ответа.
  Дополнения impersonate, cookies, android, browser и server не устанавливаются.
- Сборочный hook запускает git rev-parse и создаёт build/_commit.py. Он проверен;
  сборка выполняется без root. Установочные скрипты и CI репозитория не запускаются.
  GitHub Actions в личном форке отключены.

Исследованы сообщения об уязвимостях и ключевые изменения исправлений в репозиториях
разработчиков. Полного построчного аудита всех изменений зависимостей не проводилось.
OSV не выявила известных уязвимостей для 77 рабочих и 7 сборочных зависимостей
под Linux x86_64 / Python 3.12. Это состояние базы на дату проверки.
Старые версии для Python 3.10 остались в универсальном uv.lock и не входят
в runtime.lock этой установки; проверка не распространяется на другие платформы.
Все устанавливаемые зависимости — готовые wheel с проверкой SHA-256.

## Контроль обновлений

Никаких git pull, uv sync без --frozen, pip upgrade, uvx или автоматических
загрузок последней версии при запуске. Исправление первоначального набора
разрешено владельцем отдельно в текущем разговоре. Последующие изменения
исходного проекта и зависимостей требуют проверки и подтверждения владельца.

## Авторизация

Google-вход, получение, создание и перенос Master Token не выполнялись.
Сетевые функциональные проверки с аккаунтом требуют отдельного разрешения.
Действующий Master Token позволяет восстановить cookies после перезапуска;
отозванный Master Token восстановить невозможно: требуется новый разрешённый вход.
При утечке нужна явная отмена соответствующего устройства/сессии Google;
смена пароля сама по себе не считается достаточной мерой.

## Локальные тесты согласованного патча

Запущены от пользователя notebooklm через unshare --net, без внешней сети.
355 тестов авторизации, сокрытия секретов, доменов и файловых ограничений прошли;
2 платформенных теста пропущены. 401 тест MCP прошёл, 3 предупреждения
об устаревающем синтаксисе в тестах. Всего 756 пройденных, 2 пропущенных.
Один первоначально выбранный тест очистки VCR-записей не запускался из-за отсутствия
необязательного vcrpy; итоговый набор его не включает. Реальные Google-токены не нужны.
Проверен синтаксис 549 исходных Python-файлов и запускающего shell-скрипта.
